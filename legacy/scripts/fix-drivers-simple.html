🔧 Fix Driver PINs

⚠️ Important: This tool will add the default PIN (1234) to all drivers who don't have a PIN set. Make sure you've deployed your Cloud Functions first!

This tool will:

  • Scan all drivers in your Firestore database
  • Add PIN hash for drivers missing it
  • Use default PIN: 1234
  • Drivers will be forced to change PIN on first login
